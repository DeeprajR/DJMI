# Phase 9 — PWA installability and app-shell caching

**Status:** Complete · 2026-09-06

## Goal

Make the app installable on a phone while guaranteeing that no clinical data is ever
served from a cache.

## What was built

- `src/app/manifest.ts` — web app manifest at `/manifest.webmanifest`
- `public/sw.js` — service worker
- `src/components/pwa-register.tsx` — registration, production only
- `/offline` — fallback page
- Icons served from route handlers: `/icons/icon-192`, `/icons/icon-512`,
  `/icons/icon-512-maskable`
- Cache-control headers for `/sw.js` and the manifest in `next.config.ts`

## Caching policy

Deliberately conservative:

| Request | Strategy |
|---|---|
| App shell, static assets, icons, `/offline` | Cache-first, precached allowlist |
| Navigations | Network-only, falling back to `/offline` |
| `/api/*`, RSC payloads, clinical routes | **Network-only** |
| Offline API call | `503` with an explicit connectivity-required message |
| Any non-`GET` | Not intercepted at all |

There is **no offline write queue**. A queued clinical mutation could be replayed against
changed state hours later, so writes always require live connectivity.

## Verification

`npm run lint`, `npm run typecheck`, `npm run build` passed. Later, live cache inspection
in the browser confirmed the cache held only `/offline`, the manifest, icons, and
`_next/static` assets — no authenticated page, API response, or sign-in page.

## Notes

Icons are generated by route handlers using `next/og` rather than committed binaries. The
environment had no image tooling available (`sharp` was not resolvable standalone and
ImageMagick was absent), and generated routes avoid committing binary assets.

Native install prompts and real-device offline behaviour were not tested.

## Decisions

- **Installability without offline data.** The value is home-screen launch and a fast
  shell, not offline capability. Conflating the two invites stale clinical data.
- **Explicit `503` for offline API calls.** A clear failure is safer than a silent one that
  a caller might mistake for success.
